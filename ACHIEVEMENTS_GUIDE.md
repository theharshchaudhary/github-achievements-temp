# GitHub Achievements Guide

## Status

| Badge | How | Status |
|---|---|---|
| Quickdraw | Closed issue #1 within seconds of opening it | Done |
| YOLO | Merged PR #2 without a review (bypassed a required-review rule as admin) | Done |
| Pair Extraordinaire | Merged PR #3 with a `Co-authored-by:` commit trailer | Done |
| Pull Shark | 8 merged PRs (#2–#9) | Bronze (2) reached |
| Galaxy Brain | Accepted answers in Discussions | Manual — see below |
| Starstruck | Stars on a repository you own | Manual — see below |

Badges can take anywhere from a few minutes to a day to appear on your profile.

## Galaxy Brain

Earned when an answer you write in a **Q&A-category GitHub Discussion** is marked as the accepted answer.

Tiers: 2 / 8 / 16 / 32 accepted answers.

What to do:

1. Find active Q&A discussions: search GitHub for `is:open is:unanswered` under
   **Discussions**, or browse the Discussions tab of tools you already use
   (e.g. `vercel/next.js`, `community/community`, `microsoft/vscode`).
2. Pick questions you can genuinely answer — ideally ones you can reproduce or
   have solved before.
3. Write a clear answer: explain the cause, give a minimal fix or code
   snippet, and link docs where relevant.
4. Follow up if the asker replies. Only the asker (or a maintainer) can mark an
   answer as accepted — a helpful, correct answer is the only reliable path.

Note: answers accepted in discussions on your own repositories do not count reliably,
and asking others to accept low-effort answers violates GitHub's Acceptable Use Policies.

## Starstruck

Earned when a repository **you own** receives stars from other users.

Tiers: 16 / 128 / 512 / 4096 stars.

What to do:

1. Build something useful and small: a CLI tool, a template, a VS Code snippet
   pack, a curated list, or a well-documented project from coursework.
2. Make it easy to adopt: a clear README with a screenshot/GIF, install steps,
   usage examples, and a license.
3. Share it where the audience is: relevant subreddits, Dev.to / Hashnode posts,
   X/LinkedIn, Discord communities, or "Show HN" for polished tools.
4. Add topics (repo **Settings → About → Topics**) so it shows up in GitHub search.

Note: buying stars or star-for-star rings violates GitHub's terms and can get
the account flagged.

## Other earnable badges

- **Pull Shark (higher tiers):** 16 / 128 / 1024 merged PRs. Contributing real PRs to
  open-source projects is the best way to progress.
- **Public Sponsor:** sponsor any open-source developer through GitHub Sponsors.

## Cleanup

This repo was created only to trigger achievements. Once the badges appear, archiving
it is the safe option — it keeps the history the badges were earned from:

```
gh repo archive theharshchaudhary/github-achievements-temp
```
